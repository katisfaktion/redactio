# Redactio – Windows-Kurzstart

Benötigt wird Windows 11 (64 Bit). Das ZIP vollständig in einen lokalen Ordner
entpacken, zum Beispiel `Dokumente\Redactio`. Anschließend `redactio.exe` öffnen.
Nicht direkt aus dem ZIP oder von einem Netzlaufwerk starten. Administratorrechte
und eine separate Installation von Python, Node oder WebView2 sind nicht nötig.

Die Ordner `sidecar`, `models` und `webview2` müssen neben `redactio.exe` bleiben.
Sie enthalten die mitgelieferte Verarbeitung und Browserlaufzeit. Modelle werden
nicht aus dem Internet nachgeladen. Bei einer Meldung über fehlende oder defekte
Ressourcen das vollständige Original-ZIP erneut in einen neuen Ordner entpacken.
Eigene Quelldokumente und Arbeitsausgaben dabei nicht überschreiben.

Diese frühe Paketprüfung bestätigt ausschließlich Startressourcen und synthetische
Verarbeitung. Die vollständige Freigabe einschließlich Prüfung und Export steht
noch aus. Ergebnisse vor jeder Weitergabe fachlich prüfen; unerkannte Angaben
können weiterhin Personen identifizieren.
